# ScopeGuard AI

ScopeGuard AI is an AI-powered project scope management application that helps freelancers and agencies keep track of project agreements and identify scope creep before it becomes a problem.

## Live Demo

https://scopeguard-ai-green.vercel.app

## GitHub Repository

https://github.com/muhammadwaleedqazi/scopeguard-ai

---

## Features

- AI-powered project requirement analysis
- AI scope change detection
- Structured project records
- Risk assessment
- Suggested client responses
- Local project storage
- Export project data as JSON
- Print-friendly reports
- Modern responsive UI
- Activity timeline
- Copy-to-clipboard actions
- Toast notifications

## How it Works

1. Create a new project.
2. Paste the original client agreement.
3. Analyse the agreement using AI.
4. Save the structured project record.
5. Paste new client requests.
6. Detect scope changes using AI.
7. Review the generated risk assessment and suggested response.

## Installation

```bash
git clone https://github.com/muhammadwaleedqazi/scopeguard-ai.git

cd scopeguard-ai

npm install

npm run dev
```

---

## Environment Variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_N8N_ANALYSE_WEBHOOK_URL=YOUR_ANALYSE_WEBHOOK

NEXT_PUBLIC_N8N_SCOPE_WEBHOOK_URL=YOUR_SCOPE_WEBHOOK
```
